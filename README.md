# Kirklands Lane, Fernleigh NSW — 3D terrain viewer with live GPS

Single-file WebGL viewer (`index.html`, works offline once loaded).

- Terrain: AWS Terrarium DEM (z14); imagery: Esri World Imagery (z16)
- Lots: NSW Spatial Services cadastre; new Lot 1 / Lot 2 from Ballina DA 2024/110 (PAN-645215) stamped plans, placed from surveyed bearings (±10–20 m)
- Zoning: Ballina LEP 2012 (NSW Planning); bushfire prone land layer
- GPS needs HTTPS — open via GitHub Pages, not as a local file.

Indicative only — not a survey.
